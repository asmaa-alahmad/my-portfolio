Asmaa Alahmad — Portfolio (pure HTML / CSS / JS + 3D)
======================================================

This archive contains the full source of the portfolio.

Files
-----
- index.html ............ Self-contained single-file portfolio
                          (CSS and JavaScript inlined). Just double-click
                          to open in any modern browser. Three.js is
                          loaded from a CDN, so an internet connection
                          is required for the 3D background.
- asmaa-alahmad-cv.pdf .. Asmaa's CV (linked from the "Download CV" button).
- README.txt ............ This file.

Want the split source (3 separate files)?
-----------------------------------------
The same project also ships as three files in the live project:
  - portfolio.html   (structure)
  - portfolio.css    (styling, 3D, animations)
  - portfolio.js     (Three.js 3D scene + interactions)
Open portfolio.html through any static web server, or just open the
self-contained index.html included here.

Sections included
-----------------
Hero (3D animated), stats, about, skills, experience timeline,
education, certifications, languages, contact, sticky footer.

Features
--------
- Three.js 3D background (wireframe shapes + particle field, mouse parallax)
- CSS 3D tilt cards
- Scroll-reveal animations, count-up stats, animated language bars
- Dark / light theme toggle (remembered in localStorage)
- Mobile menu, scroll progress bar, cursor glow
- Fully responsive, no frameworks

Built for Asmaa Alahmad — Web Developer & Designer.
